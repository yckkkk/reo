# 默认封面生成提示词

Built-in `image_gen` mode. 共 6 张，统一约束：方图、无文字、无 logo、无水印、可作为横向列表项左侧缩略图。

## Cover 01

```text
Use case: illustration-story
Asset type: default cover image for a local-first memory app list item
Primary request: Generate one square cover illustration, no text, no letters, no logos, no watermark.
Scene/backdrop: a quiet tabletop with scattered handwritten notes, a small audio waveform card, and soft morning light.
Subject: memory-making materials arranged as a calm personal archive moment.
Style/medium: polished editorial raster illustration, soft shapes, tactile paper texture, sophisticated and restrained, not childish.
Composition/framing: square 1:1, clear focal composition, usable as a cropped thumbnail on the left third of a horizontal list item.
Color palette: warm off-white, charcoal, muted red accent, sage, dusty blue; avoid dominant purple/blue gradients and avoid beige-only palette.
Constraints: no readable text, no UI screenshot, no device brand, no people, no watermark.
```
