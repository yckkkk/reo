边界：
- 只使用下方 workspace-relative path，不要使用绝对路径。
- 不要编辑 `.reo/index.json`、`.reo/objects/**`、`.reo/review/**`、draft、trash 或 lock 文件。

- Widget frontmatter 必须包含 `kind: widget`、`format: html`、`mount: workspace-rail`。
